# Terminal-Based Process RPG

A terminal-based C project that demonstrates operating-system process concepts through a game-style simulation. It explores process creation and coordination, along with inter-process communication mechanisms used by the implementation.

- **Process Management:** Demonstrates process creation using POSIX system calls such as `fork()` where implemented.
- **Inter-Process Communication:** Uses pipes or other implemented mechanisms to exchange information between processes.
- **Terminal Simulation:** Presents the process-based logic through a command-line game scenario.
- **Event Logging:** Records relevant events or outcomes to files where supported.
- **Learning Focus:** Connects C programming with operating-system concepts such as processes and communication.

## Technologies Used

C · POSIX System Calls · Process Management · Pipes · Inter-Process Communication

## Project Workflow

1. Compile the C source files in a compatible environment.
2. Run the program from the terminal.
3. Observe the process-based simulation.
4. Review the communication and logging behavior implemented by the program.

## How to Run

1. Clone or download the repository.
2. Use Linux or another compatible POSIX environment with a C compiler.
3. Follow the repository's build instructions or compile the required source files.
4. Run the generated executable from the terminal.
